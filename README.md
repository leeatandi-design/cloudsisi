 CloudSisi: Your AZ-900 AI Study Buddy 🇰🇪

CloudSisi is an AI-powered study companion built for the #1MillionDevs Vibe Coding Hackathon. It is designed to help beginners prepare for the Microsoft Azure Fundamentals (AZ-900) exam by explaining complex cloud concepts using everyday African analogies (like Matatus, M-Pesa, and local markets).

Disclaimer This is an **unofficial** study tool. It is not affiliated with, endorsed by, or sponsored by Microsoft. All content is original and based on the public AZ-900 skills outline on Microsoft Learn. No real exam questions are used.

🚀 Features
- Simplified Explanations: Explains topics like VMs, Containers, ExpressRoute, and Azure Policy using relatable local analogies.
- Language Toggle (Swahili):Translates core concepts into Swahili while keeping technical English terms in brackets to ensure learners are still prepared for the English-based exam.
- Clean, Responsive UI:Built with a modern, mobile-friendly design.
- No Backend Required:Uses a custom JavaScript Knowledge Base (KB) array to simulate AI responses instantly.

🛠️ How It Was Built (Vibe Coding)
- Claude.ai: Used extensively for Prompt Engineering and generating the single-file HTML/CSS/JS application.
- Tailwind CSS: For rapid UI styling.
- Netlify: For instant hosting and deployment.

 🧠 How to Add Topics
The app is easily scalable. To add new concepts, simply open `index.html`, locate the `KB` (Knowledge Base) array in the JavaScript section, and add a new object with keywords, English text, and Swahili text. The UI will automatically generate the new topic button.
